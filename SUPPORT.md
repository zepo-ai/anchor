# Getting help

- **Documentation:** <https://sotarak.github.io/anchor/>, including
  [troubleshooting](https://sotarak.github.io/anchor/troubleshooting/).
- **Questions and ideas:** [GitHub Discussions](https://github.com/sotarak/anchor/discussions).
- **Bugs:** [open an issue](https://github.com/sotarak/anchor/issues/new/choose) with the bug report
  form. Remove secret values and tokens from logs before you paste them.
- **Security vulnerabilities:** never in public. Follow [SECURITY.md](SECURITY.md).

Anchor is maintained in spare time; there is no paid support at the moment.
