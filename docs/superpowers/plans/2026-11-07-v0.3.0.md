# v0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Anchor 0.3.0 with these four changes:
- a working Deploy to Cloudflare button, with the Wrangler config at the repo root;
- a polished dashboard (pointer cursors, tidy and animated tables, no `·`);
- README screenshots plus a CLI GIF from a reproducible pipeline;
- docs that cover every install and upgrade path.

**Architecture:**
- **Dashboard (Tasks 1–4):** global fixes live in shared places, enforced by lint rules and tests:
  - `globals.css` base styles;
  - the UI primitives;
  - `scripts/lint-tokens.mjs`.
- **Wrangler config move (Task 5):** a structural change. Every consumer of the config (vitest,
  e2e server, CLI e2e harness, docs) follows it, and a node-environment test pins what the
  Deploy button needs.
- **Media (Task 6):** produced by a separate Playwright config against a seeded local instance.
  README and docs (Tasks 7–8) consume the media and the new deploy path.
- **Release (Task 9):** bumps the version and runs the owner-verified button test before merge
  and tag.

**Tech Stack:**
- React 19, Tailwind 4.3, radix-ui and tw-animate-css.
- Vitest with Testing Library, Playwright 1.64.
- Wrangler 4.158 and Workers Builds.
- vhs (Charm) for the terminal GIF.
- pnpm 12 workspaces and Starlight docs.

**Spec:** `docs/superpowers/specs/2026-11-07-v0.3.0-design.md`

## Global Constraints

- **Version and changelog:**
  - Version `0.3.0` in all six manifests (`package.json`, `apps/{server,web,cli,docs}/package.json`,
    `packages/shared/package.json`).
  - CHANGELOG section `## [0.3.0] - <YYYY-MM-DD>` plus link refs.
- **Deploy button:**
  - Button markdown, exactly:
    `[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/sotarak/anchor)`
  - The **Workers Paid** requirement is stated next to every Deploy button.
  - Root `deploy` script, exactly: `wrangler d1 migrations apply DB --remote && wrangler deploy`.
  - Humans run `pnpm deploy:worker`. No doc line may tell anyone to run bare `pnpm deploy`.
- **Dashboard:**
  - Colors and text sizes come from tokens only (`pnpm --filter @anchor/web lint:tokens` stays
    green), and copy is sentence case.
  - Motion is 150–200 ms, and none under `prefers-reduced-motion: reduce`.
  - Dashboard source has no `·` (U+00B7) and no `cursor-default`.
- **Demo media:**
  - Demo data is fake, with no `anc_(s|st|inv|rst)_` string of real length. No one-time reveal
    dialog is ever captured.
  - The CLI recording uses `ANCHOR_CREDENTIAL_STORE=file` with a temporary `XDG_CONFIG_HOME`.
- **Commits:**
  - Each commit is signed off with `git commit -s`, and the message ends with
    `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Code, comments, commits and docs are in English.
- **Workspace:** work on branch `feat/v0.3.0`, created from `origin/main` in an isolated worktree.
  The first commit adds this plan and its spec (`docs: plan v0.3.0`).

## Review Focus

1. **Existing manual installs** upgrading from 0.2.0 still have `database_id` in
   `apps/server/wrangler.jsonc` and `.dev.vars` in `apps/server/`. After pulling 0.3.0, both must
   be moved to the root, or deploys create a new empty database.
   - Task 8's upgrade guide and Task 9's CHANGELOG must say so.
   - Pinned by `repository.test.ts › the 0.3.0 changelog tells manual installs to move database_id`.
2. **Workers Builds may run `deploy` through npm, not pnpm.** The script must not invoke `pnpm`.
   - Pinned by `deploy-button.test.ts › the deploy script uses no pnpm`.
3. **A fresh button deploy where the dead-letter queue `anchor-reencrypt-dlq` is not
   auto-provisioned** fails on its first deploy.
   - Pinned only by the owner's live button test (Task 9, Step 4), which has a written
     contingency.
4. **A secret with a 300-character comment** must not grow its row or push the Value column. The
   comment cell truncates, and the full text is in a tooltip.
   - Pinned by `secrets.test.tsx › a long comment is truncated in its own column`.
5. **Users with reduced motion get no animation**, and keyboard focus is not hidden by the new
   cursor rules.
   - Pinned by `styles.test.ts › reduced motion removes animation and transition time`.
